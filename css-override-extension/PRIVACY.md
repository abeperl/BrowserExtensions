# Privacy Policy for CSS Override Extension

**Last Updated:** August 27, 2025

This Privacy Policy describes how the CSS Override Extension ("we", "us", or "our") collects, uses, and protects information when you use our browser extension.

## Information We Collect

### Local Storage Only
- **CSS Rules**: Your custom CSS rules and URL patterns are stored locally on your device using Chrome's storage API
- **Settings**: Extension preferences and configuration options
- **No Personal Data**: We do not collect, store, or transmit any personal information

### Technical Data
- **Extension Usage**: Basic usage statistics (stored locally only)
- **Error Logs**: Technical error information for debugging (stored locally only)

## How We Use Information

### Local Processing
- CSS rules are processed locally on your device
- URL pattern matching occurs in your browser
- No data is sent to external servers

### Functionality
- Apply custom CSS rules to websites based on your configured patterns
- Store your preferences and rules for future use
- Provide extension settings and management features

## Data Storage

### Local Only
- All data is stored locally on your device
- No cloud storage or external servers are used
- Data remains on your device until you uninstall the extension

### Data Removal
- Uninstalling the extension removes all stored data
- You can clear all data through the extension's settings page
- Individual rules can be deleted through the extension interface

## Permissions and Access

The extension requires the following browser permissions:

- **Storage**: To save your CSS rules and settings locally
- **Active Tab**: To access the current tab and apply CSS rules
- **Scripting**: To inject CSS into web pages you visit
- **Tabs**: To monitor tab changes and apply rules automatically

These permissions are used solely for the extension's core functionality and are not used to collect or transmit data.

## Third-Party Services

This extension does not integrate with any third-party services, APIs, or external resources. All functionality operates locally within your browser.

## Data Security

- All data is stored using browser security mechanisms
- No data transmission occurs outside your device
- Extension follows browser extension security best practices

## Children's Privacy

This extension is not intended for children under 13 years of age. We do not knowingly collect personal information from children under 13.

## Changes to This Privacy Policy

We may update this Privacy Policy from time to time. We will notify you of any changes by:
- Updating the "Last Updated" date at the top of this policy
- Posting the updated policy within the extension
- Notifying users through the extension interface (if applicable)

## Contact Us

If you have any questions about this Privacy Policy or the extension, please:
- Create an issue on our GitHub repository
- Contact us through the extension's support channels

## Compliance

This extension complies with:
- Google Chrome Web Store Privacy Requirements
- Microsoft Edge Add-ons Privacy Requirements
- General Data Protection Regulation (GDPR) where applicable
- California Consumer Privacy Act (CCPA) where applicable

## Your Rights

You have the right to:
- Access all data stored by the extension
- Delete all data stored by the extension
- Export your CSS rules for backup purposes
- Uninstall the extension at any time

## Opt-Out

You can disable data collection by:
- Disabling the extension through browser settings
- Clearing all stored data through the extension settings
- Uninstalling the extension

---

This privacy policy applies to the CSS Override Extension only. The extension does not modify or interfere with the privacy practices of websites you visit.
