# Test Files

This folder contains test, demo, and example HTML files for the css-js-toinject project.

## Files

### Audio Testing
- **audio-test-demo.html** - Audio feedback testing interface

### Overlay Testing
- **demo-overlay-popup.html** - Overlay and popup component demonstration

### Box Label Testing
- **test-box-label.html** - Box label format testing (basic)
- **test-box-label-format.html** - Box label format testing (advanced)

### Page Samples
- **page.html** - Sample page for testing injected scripts

## Usage

These files are for local development and testing only. They are not deployed to production.

To use:
1. Open any HTML file in a web browser
2. Test the corresponding feature or component
3. Verify functionality before integrating into main scripts

## Organization

All test and demo files have been moved to this folder to keep the main project directory clean and organized.
